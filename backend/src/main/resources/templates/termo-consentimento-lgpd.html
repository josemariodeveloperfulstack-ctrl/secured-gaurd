Em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD - Lei nº 13.709/2018), este termo tem como objetivo registrar o consentimento livre, informado e inequívoco do titular para o tratamento de seus dados pessoais pela empresa.

O titular está ciente de que seus dados pessoais serão tratados pela empresa para as finalidades específicas descritas neste termo, podendo exercer seus direitos de acesso, correção, exclusão, portabilidade e revogação do consentimento a qualquer momento.

DIREITOS DO TITULAR:

O titular tem direito a obter da empresa, a qualquer momento, mediante requisição:

  • Confirmação da existência de tratamento de dados pessoais;
  • Acesso aos dados pessoais;
  • Correção de dados incompletos, inexatos ou desatualizados;
  • Anonimização, bloqueio ou eliminação de dados desnecessários;
  • Portabilidade dos dados a outro fornecedor;
  • Eliminação dos dados tratados com consentimento;
  • Informação sobre compartilhamento de dados;
  • Revogação do consentimento.

DECLARAÇÃO DE CONSENTIMENTO

Declaro que fui informado(a) de forma clara e compreensível sobre a coleta, uso, armazenamento e compartilhamento dos meus dados pessoais. Autorizo expressamente o tratamento dos meus dados pessoais para as finalidades especificadas neste termo, estando ciente dos meus direitos como titular de dados pessoais.
