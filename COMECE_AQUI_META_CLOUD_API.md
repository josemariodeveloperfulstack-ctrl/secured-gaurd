## 🎯 **3 PASSOS SIMPLES:**

### 📱 **PASSO 1: OBTER CREDENCIAIS (30 min)**

Acesse e siga o guia:
```
📄 GUIA_META_WHATSAPP_CLOUD_API.md
```

**Link direto:**
```
https://developers.facebook.com/
```

**Você vai obter:**
1. ✅ **PHONE_NUMBER_ID** (15-20 dígitos)
2. ✅ **ACCESS_TOKEN** (começa com EAA...)

---

### ⚙️ **PASSO 2: CONFIGURAR (2 min)**

Edite o arquivo:
```
backend/src/main/resources/application.properties
```

Encontre e substitua:
```properties
whatsapp.meta.phone-number-id=COLE_SEU_PHONE_NUMBER_ID_AQUI
whatsapp.meta.access-token=COLE_SEU_ACCESS_TOKEN_AQUI
```

**Salve o arquivo!**

---

### 🔄 **PASSO 3: REINICIAR BACKEND (1 min)**

Duplo clique no arquivo:
```
reiniciar_backend_meta_api.bat
```

Ou execute manualmente:
```powershell
cd C:\dev\secured-guard\backend
.\mvnw clean compile
.\mvnw spring-boot:run
```
